# Gerador de Tabela Verdade Completa em Python
Este projeto apresenta a construção automatizada de uma **Tabela Verdade Completa** com 3 proposições (`P`\), \(`Q`\) e \(`R`\) utilizando a linguagem Python. O objetivo é demonstrar a aplicação da **Lógica Matemática** para mapeamento de validação de dados na engenharia de software.
## Funcionalidades
Automação por meio da utilização do módulo nativo python 'itertools' para mapear todas possibilidades para as variáveis P, Q, R.
Mapeamento de todas as combinações possíveis (8 cenários para 3 variáveis). 
**Formatação Limpa:** Interface limpa do terminal usando máscaras de alinhamento (`:<4`, `:<6`) para espaçamento das colunas e conversão booleana para caracteres tradicionais Verdadeiro (`V`) Falso (`F`).
  
## Estrutura da Tabela Verdade:
1.**( P\ ) Proposição de entrada 1**

2.**(Q\ ) Proposição de entrada 2**

3.**(R\ ) Proposição de entrada 3**

4.**(P_and_Q) Conjunção de operador 'and'**

5.**(not_P_and_Q) Negação de operador 'not'**

6.**(P_and_Q → R) Implicação**
